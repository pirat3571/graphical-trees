Индексация символов

Индексный массив хранит не сами символы, а их позиции в исходной строке, упорядоченные по коду символа. Направление сортировки и фильтры «только гласные» / «только согласные» задаются флагами.

Если ни один флаг не включён — берутся все буквы. Флаги взаимоисключающие. Пробелы и знаки препинания не учитываются; позиции считаются по буквам.
Что такое индексный массив

Пусть дана строка СОРТ. Если упорядочить её символы по возрастанию, получится ОРСТ. Индексный массив хранит, откуда взят каждый символ: [1, 0, 2, 3] — позиция буквы «О» (1), затем «Р» (0), затем «С» (2), затем «Т» (3).

Такое представление удобно для поиска и сравнения строк: сами символы остаются на своих местах, а переставляется только небольшой массив целых чисел. Дополнительные флаги позволяют строить индекс только по подмножеству символов, например только по гласным.

Как работают флаги

Только гласные. В индекс попадают гласные русские (а, е, ё, и, о, у, ы, э, ю, я) и латинские (a, e, i, o, u, y) буквы. Только согласные. В индекс попадают остальные буквы, кроме мягкого и твёрдого знаков. Если флаги выключены, участвует вся строка.

Сортировка всегда устойчивая: одинаковые символы сохраняют исходный порядок позиций. При убывании направление сравнения просто меняется на противоположное.
