Оптимальное дерево поиска: точный алгоритм

Каждому ключу задан вес (частота обращения). Нужно построить двоичное дерево поиска с минимальной суммарной стоимостью поиска. Точный алгоритм — динамическое программирование: для каждого отрезка ключей перебираются все варианты корня, а результаты меньших отрезков уже известны.

Таблица динамического программирования

C[i,j] — минимальная стоимость дерева для ключей i…j; под числом указан выбранный корень. W(i,j) — сумма весов отрезка.
Формула и почему алгоритм точный

Для отрезка ключей i…j обозначим W(i,j) сумму их весов. Если корнем выбрать ключ r, его вес войдёт в стоимость один раз, а все ключи левого и правого поддеревьев опустятся на уровень ниже — то есть добавят ещё W(i,j). Поэтому

C[i,j] = W(i,j) + mini≤r≤j ( C[i,r−1] + C[r+1,j] ), где C[i,i−1]=0.

Ячейки заполняются по возрастанию длины отрезка. Оптимальная стоимость — C[0,n−1], а выбранные корни R[i,j] позволяют восстановить само дерево. Сложность — O(n³), поэтому точный алгоритм применяют при небольших n.
