# Алгоритмы по шагам

Статический сайт-тренажёр: сортировки, поиск, индексация, хеширование и деревья с пошаговой визуализацией и объяснениями. Все вычисления выполняются локально в браузере.

## Запуск

Откройте `index.html` в браузере. Сервер и сборка не нужны.

Ну или перейдите по ссылке [![Открыть сайт](https://shields.io)](https://pirat3571.github.io/graphical-trees/)


## Страницы

| Файл | Что показывает |
|---|---|
| `isdp.html` | ИСДП — идеально сбалансированное дерево поиска |
| `sdp.html` | СДП — случайное дерево поиска |
| `sdp-delete.html` | Удаление из СДП (три случая) |
| `avl.html` | Построение АВЛ-дерева, повороты LL/RR/LR/RL |
| `avl-delete.html` | Удаление из АВЛ-дерева с балансировкой |
| `btree.html` | Двоичное Б-дерево поиска (B-дерево порядка 3–6) |
| `optimal-exact.html` | Оптимальное дерево поиска, точный алгоритм ДП |
| `optimal-approx.html` | Оптимальное дерево поиска, два приближённых алгоритма |

## Общие файлы

- `assets/style.css` — оформление, светлая и тёмная темы, адаптивность.
- `assets/core.js` — парсинг ввода, раскладка и рисование деревьев, пошаговый плеер.
- `assets/algo.js` — столбики сортировок, карманы цифровой сортировки и вспомогательные визуализации.

Управление: кнопки «Назад / Дальше», ползунок шага, «Авто», клавиши ← и →.
