Кодирование по шагам

Четыре кода: Шеннона, Фано, Хаффмана и Гилберта—Мура. Вероятности символов оцениваются по частотам с точностью до двух знаков. Для каждого кода проверяется неравенство Крафта, вычисляется средняя длина кодового слова и сравнивается с энтропией и остальными кодами.

До 40 символов, повторы разрешены — именно частота повтора задаёт вероятность. pi = ni / N с округлением до 0,01.

Метрики кода

—H — энтропия, бит
—L — средняя длина
—Σ 2−l — Крафт
—L − H
Постройте код, чтобы увидеть метрики.
Как оцениваются вероятности

Вероятность символа оценивается по всей выборке: pi = ni / N, где ni — сколько раз символ встретился, N — длина набора. Значение округляется до двух знаков после запятой, как требуется в задании. Из-за округления сумма pi может немного отличаться от 1 — все дальнейшие расчёты (энтропия, длины, Крафт, L) ведутся именно по округлённым вероятностям.

Неравенство Крафта и энтропия

Неравенство Крафта. Префиксный код с длинами слов li существует тогда и только тогда, когда Σ 2−li ≤ 1. Все четыре кода — Шеннона, Фано, Хаффмана и Гилберта—Мура — префиксные, поэтому для каждого построенного кода сумма не превосходит единицы; мы проверяем это явно.

Энтропия H = −Σ pi·log₂pi — теоретический предел средней длины: любой однозначно декодируемый код имеет L ≥ H. Средняя длина L = Σ pi·li измеряется в битах на символ. Разность L − H — избыточность кода.

Код Шеннона

Символы упорядочиваются по убыванию вероятности. Длина кодового слова li = ⌈−log₂pi⌉ — так каждому символу отводится «его» количество бит. Кодовое слово — первые li бит двоичной записи накопленной вероятности Qi = p1 + … + pi−1.

Гарантия: L < H + 1 — не более чем на бит хуже предела, при этом длины вычисляются напрямую, без построения дерева.

Код Фано

Отсортированный по убыванию вероятностей список рекурсивно делится на две части с максимально близкими суммами вероятностей. Верхней части приписывается бит 0, нижней — бит 1; внутри каждой части деление повторяется, пока в группе не останется один символ.

Код Фано почти всегда близок к оптимальному, но, в отличие от кода Хаффмана, оптимум не гарантирует.

Код Хаффмана

Жадный алгоритм: на каждом шаге берутся два узла с наименьшими вероятностями и сливаются в новый узел с суммарной вероятностью, который возвращается в очередь. Когда остаётся один узел, получается дерево: левое ребро — бит 0, правое — бит 1, код символа читается от корня к его листу.

Код Хаффмана — оптимальный префиксный код: его средняя длина L минимальна среди всех префиксных кодов для данной таблицы вероятностей, поэтому в итоговом сравнении она не превосходит L кодов Шеннона и Фано.

Код Гилберта—Мура

Символы остаются в исходном (алфавитном) порядке — сортировать их не нужно. Для каждого символа берётся середина его интервала: Qi = p1 + … + pi−1 + pi/2. Длина слова li = ⌈−log₂pi⌉ + 2, а само слово — первые li бит двоичной записи Qi.

Запасной разряд гарантирует, что двоичный интервал кодового слова целиком лежит внутри интервала символа, — код всегда префиксный. Средняя длина у Гилберта—Мура заметно больше, чем у Хаффмана, зато код назначается по алфавиту без перестроения (в варианте Шеннона—Фано—Элиаса с одним запасным разрядом L ≤ H + 2).
