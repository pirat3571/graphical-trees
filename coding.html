Кодирование по шагам

Пять способов кодирования: арифметический код и коды Шеннона, Фано, Хаффмана и Гилберта-Мура, плюс вкладка с декодированием. Вероятности символов оцениваются по частотам. Для каждого побуквенного кода строятся таблица и дерево, проверяется неравенство Крафта, вычисляется средняя длина слова и сравнивается с энтропией.

До 40 символов, повторы разрешены (именно частота повтора задаёт вероятность). pi = ni / N с округлением до 0,01.

Метрики кода

—H — энтропия, бит
—L — средняя длина
—Σ 2−l — Крафт
—L − H
Постройте код, чтобы увидеть метрики.
Как оцениваются вероятности

Вероятность символа оценивается по всей выборке: pi = ni / N, где ni — сколько раз символ встретился, N — длина набора. Значение округляется до двух знаков после запятой. Из-за округления сумма pi может немного отличаться от 1 — все дальнейшие расчёты (энтропия, длины, Крафт, L) ведутся именно по округлённым вероятностям.

Неравенство Крафта и энтропия

Неравенство Крафта. Префиксный код с длинами слов li существует тогда и только тогда, когда Σ 2−li ≤ 1. Все четыре кода — Шеннона, Фано, Хаффмана и Гилберта—Мура — префиксные, поэтому для каждого построенного кода сумма не превосходит единицы; мы проверяем это явно.

Энтропия H = −Σ pi·log₂pi — теоретический предел средней длины: любой однозначно декодируемый код имеет L ≥ H. Средняя длина L = Σ pi·li измеряется в битах на символ. Разность L − H — избыточность кода.

Логарифмы или дроби: как найти длину слова

Длина слова по определению L = ⌈−log₂p⌉, то есть наименьшее целое, при котором 2−L ≤ p. Считать логарифм не обязательно: достаточно подобрать степень двойки из неравенства 1/2L ≤ p < 1/2L−1. Например, для p = 0,36: 1/4 ≤ 0,36 < 1/2, значит L = 2. Результат тот же, но вручную считать проще.

Для кода Гилберта-Мура берётся L = ⌈−log₂p⌉ + 1, то есть неравенство 1/2L−1 ≤ p < 1/2L−2. В арифметическом коде число бит k — наименьшее k, для которого 1/2k ≤ r, где r — длина итогового интервала. Логарифм нужен только для энтропии H.

Побуквенное кодирование: разделимые и префиксные коды

Побуквенный код ставит каждому символу алфавита своё кодовое слово, а код сообщения собирается из слов его символов. Код называется разделимым, если любое закодированное сообщение декодируется однозначно, и префиксным, если ни одно слово не является началом другого. Всякий префиксный код разделим, обратное неверно.

Декодирование по дереву. Читаем биты и идём от корня: 0 влево, 1 вправо. Дошли до листа, значит выдаём его символ и возвращаемся в корень. Для префиксного кода слова лежат только в листьях, поэтому разделители не нужны.

Избыточность кода r = Lср − H показывает, насколько средняя длина слова больше энтропии. Оптимальный код имеет наименьшую избыточность.

Код Шеннона

Символы упорядочиваются по убыванию вероятности. Длина кодового слова li = ⌈−log₂pi⌉ — так каждому символу отводится «его» количество бит. Кодовое слово — первые li бит двоичной записи накопленной вероятности Qi = p1 + … + pi−1.

Гарантия: L < H + 1 — не более чем на бит хуже предела, при этом длины вычисляются напрямую, без построения дерева.

Код Фано

Отсортированный по убыванию вероятностей список рекурсивно делится на две части с максимально близкими суммами вероятностей. Верхней части приписывается бит 0, нижней — бит 1; внутри каждой части деление повторяется, пока в группе не останется один символ.

Код Фано почти всегда близок к оптимальному, но, в отличие от кода Хаффмана, оптимум не гарантирует.

Код Хаффмана

Жадный алгоритм: на каждом шаге берутся два узла с наименьшими вероятностями и сливаются в новый узел с суммарной вероятностью, который возвращается в очередь. Когда остаётся один узел, получается дерево: левое ребро — бит 0, правое — бит 1, код символа читается от корня к его листу.

Код Хаффмана — оптимальный префиксный код: его средняя длина L минимальна среди всех префиксных кодов для данной таблицы вероятностей, поэтому в итоговом сравнении она не превосходит L кодов Шеннона и Фано.

Код Гилберта-Мура

Символы стоят в алфавитном порядке: a1 ≤ a2 ≤ … ≤ an. Код алфавитный: кодовые слова идут в том же порядке, что и символы. Для каждого символа берётся середина его интервала: Qi = p1 + … + pi−1 + pi/2. Длина слова Li = ⌈−log₂pi⌉ + 1, а само слово — первые Li бит двоичной записи Qi.

Лишний разряд гарантирует, что двоичный интервал слова целиком лежит внутри интервала символа, поэтому код всегда префиксный. Средняя длина больше, чем у кода Хаффмана: L < H + 2. Зато код назначается по алфавиту, без сортировки по вероятности.
